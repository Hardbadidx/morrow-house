# Cafe Premium

A premium interactive restaurant/cafe website built with Vite and React.

## Tech Stack

- React
- Vite
- JavaScript / JSX
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- React Router
- React Hook Form
- Zod
- date-fns
- lucide-react

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
